# Pokédex Project

A Pokédex web app built with HTML, CSS, and JavaScript.  
It uses the PokéAPI to load and display Pokémon data.

---

## What this project does

- Shows a list of Pokémon
- Loads more Pokémon when you click a button
- Lets you search for Pokémon by name
- Opens a detail view for each Pokémon
- Shows basic stats and types
- Has a dark mode

---

## Technologies used

- HTML
- CSS
- JavaScript
- PokéAPI (https://pokeapi.co/)
